# Макеты

`board.html` — доска макетов прототипа (вкладки «Вузы» и «Олимпиады», мобильные и десктопные
кадры). Открывается в браузере как файл.

**Устарела:** в ней нет вкладки «Дипломы», формы-шторки, тостов и состояний ошибок — эти экраны
собраны в коде из токенов макета (`apps/web/src/app/styles.css`). Источник правды по дизайну —
код и [ADR 0005](../docs/adr/0005-ui-parity-with-prototype.md).
