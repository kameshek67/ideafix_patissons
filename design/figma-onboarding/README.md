# Онбординг в Figma

Плагин рисует в файле с доской «Идея фикс» раздел **«03 · Онбординг · 430»**. В разделе три экрана
430×932 и блок «Поведение». Все слои обычные: auto layout, шрифт Onest, цвета и радиусы
из дизайн-системы (`apps/web/src/app/styles.css`). 3D-иллюстрации берутся из этого же файла.

REST API и MCP-сервер Figma умеют только читать файлы, поэтому рисует плагин внутри самой Figma.

## Запуск

Нужна Figma для компьютера: в браузерной версии плагин из файла импортировать нельзя.

1. Откройте файл с доской в Figma desktop.
2. Меню → **Plugins → Development → Import plugin from manifest…** и выберите
   `design/figma-onboarding/manifest.json`.
3. **Plugins → Development → «Олимп — онбординг»**. Раздел появится справа от доски, а плагин
   закроется сам.

Повторный запуск создаёт ещё одну копию раздела, поэтому старую удалите.

## Что на экранах

| Экран | Заголовок | Иллюстрация | Кнопки |
|---|---|---|---|
| 1 из 3 | «Выбери вуз → узнай олимпиады» | здание (illu-uni) | «Далее», «Пропустить» |
| 2 из 3 | «Олимпиада → куда с ней поступить» | кубок (illu-olymp) | «Далее», «Пропустить» |
| 3 из 3 | «Мои дипломы → все льготы сразу» | карточки дипломов и кубок | «Добавить диплом», «Начать без дипломов» |

Сверху — текст на фоне приложения (белый с фиолетовым низом), в середине — иллюстрация,
снизу — белая шторка с прогрессом и кнопками. Если иллюстраций в файле нет, на их месте
будут светлые плашки с подписью «вставьте иллюстрацию».
