# packages/llm — шлюз к языковым моделям

`olymp_llm` — единая точка вызова LLM для API (чат F-02) и воркеров (ИИ-парсеры F-07),
см. [ADR 0010](../../docs/adr/0010-llm-gateway.md).

- `gateway.py` — OpenAI-совместимый клиент: поток, вызовы инструментов, повторы, резервная модель.
- `complete()` — ответ целиком одной строкой (для парсеров).
- `provider_from_env()` — провайдер из переменных `OLYMP_LLM_*` (воркеры; API берёт настройки из `Settings`).
- `fake.py` — поддельный провайдер для тестов: модель в CI не вызывается.

Пакет не знает про БД, API и воркеры (контракт в корневом `pyproject.toml`). Текст запросов не логируется.
