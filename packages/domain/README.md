# packages/domain — чистая логика

Библиотека `olymp_domain` без базы, сети и фреймворков: её используют и API, и сборка базы.
Не зависит от `olymp_db`, `olymp_api`, `olymp_workers` — проверяет `lint-imports`.

| Модуль | Что делает |
|---|---|
| `textutils.py` | нормализация «грязного» текста из PDF, `squash()` — устойчивый ключ названия, извлечение уровня, роли, класса, подтверждающего ЕГЭ, разбор перечислений и правил «по профилю» |
| `olympiad_seeds.py` | справочник олимпиад: якоря для схлопывания ~450 вариантов написания в 173 олимпиады и сокращения («всош», «пвг», «вышка») |
| `diplomas.py` | подходит ли строка льготы конкретному диплому: профиль/предмет, «кому», класс, годы; `CAMPAIGN_YEAR` |

Новое сокращение олимпиады — в `olympiad_seeds.py` (с тестом). Новое правило разбора условий —
в `diplomas.py` или `textutils.py` с табличным тестом на реальных формулировках из XLSX.

```bash
uv run pytest packages/domain -q    # быстро, база не нужна
```
