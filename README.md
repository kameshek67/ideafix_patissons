# Олимп

Сайт и мини-приложение MAX. Школьник вводит свои олимпиадные дипломы и видит, в каких вузах они дают БВИ
(поступление без экзаменов) или 100 баллов за ЕГЭ. У каждой строки есть ссылка на документ приёмной комиссии
и номер страницы, так что всё можно проверить самому. Данные справочные: перед подачей документов сверяйся
с правилами приёма вуза.

Стенд: https://ideafix.patissons.tech.

## Зачем это нужно

Олимпиады сейчас один из главных способов поступить в сильный вуз. Но понять, что тебе даёт твой диплом,
очень сложно.

- **Олимпиадников много, и мест они занимают много.** В 2026 году в МГУ подали документы 5 107 олимпиадников
  (на 48% больше, чем годом раньше), в МФТИ они заняли 53% бюджетных мест
  ([РБК через «Эксперт»](https://expert.ru/news/rbk-olimpiadniki-zanyali-vse-mesta-na-top-napravleniyakh-veduschikh-vuzov-rossii)).
  В 2025 году в ИТМО олимпиадники заняли 47,5% бюджета, в РАНХиГС 44%
  ([Мел](https://mel.fm/novosti/1935702-predstaviteli-rossyskikh-vuzov-rasskazali-skolko-byudzhetnykh-mest-v-etom-godu-zanyali-olimpiadniki)).
  Только на заключительном этапе ВсОШ 2025 года дипломы получили 4 017 человек
  ([олимпиады.рф](https://xn--90aivcdt6dxbc.xn--p1ai/articles/news/bolee-4-tysyach-chelovek-stali-prizerami-vserossiyskoy-olimpiady-shkolnikov/)),
  а ведь есть ещё десятки перечневых олимпиад.
- **Правила у каждого вуза свои.** Важно не только название олимпиады, но и профиль, победитель ты или
  призёр, в каком классе получил диплом и сколько баллов ЕГЭ набрал по профильному предмету. Один и тот же
  диплом в одном вузе даёт БВИ, в другом только 100 баллов, а в третьем не даёт ничего.
- **Всё это лежит в PDF.** Мы посчитали на примере из нашего демо: школьнице с двумя дипломами, чтобы самой
  проверить 21 вуз, где они работают, надо прочитать не меньше 295 страниц PDF и ещё несколько страниц сайтов.
- **Правила постоянно меняются.** В перечне олимпиад на 2026/27 год осталось 60 олимпиад, а в прошлом году
  было 83. 25.11.2026 Госдума приняла поправки к закону об образовании: призёрам перечневых олимпиад
  с дипломами 2026/27 года и позже вместо БВИ будут давать 100 баллов, у победителей и ВсОШ БВИ остаётся (подписание закона мы пока не проверили, поэтому на сайте
  это переключатель «Правила 2027 (проект)»).

Если ошибиться, последствия серьёзные: школьник рассчитывает на БВИ, а его нет, и узнаёт он об этом, когда
уже поздно добирать баллы или ехать на другую олимпиаду.

## Кому это нужно

| Целевая аудитория | Зачем ей Олимп |
|---|---|
| Школьники 9–11 классов с дипломами | Узнать за минуту, куда можно поступить без экзаменов или со 100 баллами, и сколько баллов ЕГЭ ещё не хватает |
| Школьники 7–10 классов, которые только выбирают олимпиады | Режим «цель → олимпиады»: выбираешь вуз и направление, видишь, какие олимпиады туда ведут |
| Родители | Понять, во что вкладывать время и деньги на подготовку, и не пропустить льготу ребёнка |
| Учителя и классные руководители | Быстро ответить ученику, скинуть итог в чат класса кнопкой «Поделиться» |
| Онлайн-школы и кружки подготовки к олимпиадам | Показывать ученикам, что даст им олимпиада, прямо у себя на платформе через наш API |
| Вузы | Чтобы их правила для олимпиадников были описаны правильно и абитуриенты приходили с верными ожиданиями |

## Как на этом зарабатывать

Для школьников сервис бесплатный и таким останется: если брать деньги со школьника, до сервиса не дойдут те,
кому он нужнее всего. Зарабатывать можно на тех, кому наши данные помогают продавать или работать.

1. **API для онлайн-школ и сервисов профориентации.** Онлайн-школа готовит к олимпиадам и хочет показывать
   ученику: «эта олимпиада даёт БВИ в 15 вузах, вот куда ты пройдёшь с дипломом». Сама она такую базу не
   соберёт, это сотни документов, которые меняются каждый год. Мы даём API: бесплатно с лимитом запросов,
   а дальше платная подписка с ключом, большими лимитами и обновлениями сразу после изменения правил вузов.
2. **Виджет для сайтов.** То же самое, но без программиста: школа или кружок вставляет готовый блок
   «проверь свой диплом» к себе на сайт.
3. **Вузы.** Вуз платит за проверенную и аккуратно оформленную страницу своих льгот и за статистику: сколько
   школьников с какими дипломами смотрели его направления. Строки при этом не продаются: что написано
   в документе вуза, то и показываем.
4. **Школы и регионы.** Режим учителя со сводкой по классу или по школе: у кого какие дипломы, кто
   на какие вузы может рассчитывать. Это можно продавать школам и региональным центрам работы с одарёнными
   детьми.
5. **Организаторы олимпиад.** Страница олимпиады с тем, где её диплом реально даёт льготу. Организаторам
   это помогает привлекать участников.

Сейчас ни с кем из них договорённостей нет: это план, а не подписанные контракты.

## Что умеет

- Вуз и направление → олимпиады, которые дают льготы, и что нужно подтвердить на ЕГЭ.
- Олимпиада → вузы, где она даёт льготы. Поиск понимает сокращения и профили («вышка», «нто ии»).
- «Мои дипломы»: вузы и направления по дипломам. Учитываются степень, класс, год, этап ВсОШ.
  Есть переключатель «Правила 2027 (проект)». В MAX дипломы хранятся в профиле, в браузере — на устройстве.
- Баллы ЕГЭ: сайт показывает, где баллов хватает, чтобы подтвердить льготу, а где не хватает и сколько.
- «Цель → олимпиады»: до трёх направлений-целей и список олимпиад, которые к ним ведут.
- Баллы за индивидуальные достижения (ГТО, аттестат, волонтёрство) по выбранному вузу.
- Жалоба «не совпадает с документом» у каждой строки льготы; дежурный получает её в боте MAX.
- ИИ-помощник подбирает олимпиады и вузы по базе, а после ответа код сверяет его с базой. Без ключа модели он выключен.
- Ссылка «Поделиться» с результатом для чата класса.
- Страница «Качество данных» (`/quality`): насколько точно мы переносим льготы из документов и по каким вузам данных нет.

## Для онлайн-школ и других сервисов

Всё, что видит школьник на сайте, можно получить и из своей программы.

- **HTTP API.** Пути начинаются с `/v1`, описание в Swagger (`/docs`) и в [docs/openapi.json](docs/openapi.json).
  Главные запросы: дипломы → вузы и направления (`/v1/achievements/match`), олимпиада → вузы
  (`/v1/search/by-olympiad`), вуз и направление → олимпиады (`/v1/search/by-program`), цель → олимпиады
  (`/v1/goals/olympiads`).
- **MCP-сервер** (`backend/mcp`). Его можно подключить к ИИ-ассистенту, и тот будет отвечать про льготы
  по нашей базе, а не придумывать.
- **Открытый датасет** (`just dataset`): все льготы со ссылками на документы, лицензия CC BY 4.0.

Сейчас у API общий лимит запросов на посетителя, ключей для партнёров пока нет.

## Чего сейчас не хватает

Самое важное:

- **Настоящих пользователей.** Мы не тестировали сервис на школьниках. Нужно дать его хотя бы 10–20
  ученикам и посмотреть, где они путаются.
- **Вузов.** В базе 39 вузов, у 9 из них таблицы льгот пока нет (МФТИ, МИЭТ, Сеченовский университет, РГГУ,
  СФУ, ЛЭТИ, три филиала Губкина). А вузов, которые принимают олимпиадников, намного больше.
- **Проверки всей базы.** Точность мы измерили на выборке из 6 документов, а не на всех данных.

Фишки, которых очень хочется:

- **Уведомления в боте MAX.** «Вуз опубликовал правила на 2027 год, у тебя поменялось вот это», «через неделю
  заканчивается регистрация на олимпиаду, которая ведёт в твой вуз».
- **Помощь с выбором, куда подать.** БВИ можно использовать только в одном вузе на одно направление, и школьнику
  надо решить, где его потратить, а где поступать по 100 баллам или по ЕГЭ. Сейчас сайт показывает варианты,
  но не помогает выбрать.
- **Календарь олимпиад под цель.** Не только список олимпиад, но и когда регистрация и этапы, чтобы
  составить план на год.
- **Сравнение вузов.** Положить рядом 2–3 вуза и сразу увидеть, где диплом выгоднее.
- **Режим учителя.** Сводка по классу с согласия учеников.
- **Ключи API и тарифы** для онлайн-школ, виджет для сайтов.
- **Кнопка «Удалить мои данные»** и ИИ-модель от российского провайдера, чтобы можно было работать со школами
  по закону о персональных данных.
- **Кабинет для вузов**, где приёмная комиссия сама даёт ссылку на новый документ и видит, что изменится.

## Запуск

Нужен Docker.

```bash
docker compose up --build -d
```

Сайт — http://localhost:8080, API и Swagger — http://localhost:8000/docs. При первом старте сервис
`migrate` применяет миграции и собирает базу из `data/` (около минуты, `docker compose logs -f migrate`).
База лежит в томе `pgdata`. Если порты заняты, задай `OLYMP_WEB_PORT` и `OLYMP_API_PORT` в `.env`.

## Разработка

Нужны `uv`, Node.js (версия в `.nvmrc`), Docker и `just`.

```bash
cp .env.example .env
(cd backend && uv sync --all-packages) && (cd frontend && npm ci)
just up && just seed    # PostgreSQL, Redis, RabbitMQ; миграции и сборка базы
just api                # API на :8000
just web                # сайт на :3000
```

- `just check` — всё, что проверяет CI (`just lint` и `just test`). Тестам с базой нужен `just up`.
- `just openapi` — после изменения эндпоинтов: обновляет `docs/openapi.json` и `frontend/src/api/schema.d.ts`.
- `just migration "описание"` — новая миграция Alembic; файл проверь руками.
- `just data-diff` — как изменилась выдача относительно снимка; `just snapshot` — принять изменения.
- `just validate` — проверка качества собранной базы.
- `just --list` — остальные команды.

## Структура

```
backend/      Python 3.13, uv workspace
  api/          FastAPI: каталог, поиск, дипломы, жалобы, помощник
  workers/      сборка базы, обход сайтов вузов, извлечение, бот MAX
  domain/       чистая логика без базы и сети
  db/           модели SQLAlchemy и миграции Alembic
  llm/          шлюз к языковым моделям
  mcp/          MCP-сервер: инструменты поверх публичного API для внешних ассистентов
frontend/     Next.js 16: сайт и мини-приложение MAX (src/app, src/components, src/api)
data/         исходный XLSX, перечень РСОШ, снимок выдачи, эталоны, извлечённые документы
infra/        Dockerfile, окружение разработки, скрипты выкатки (infra/deploy)
docs/         документация, openapi.json, макеты (design)
```
