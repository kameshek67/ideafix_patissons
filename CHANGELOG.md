# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — `0.MINOR.PATCH`
до сдачи хакатона ([release.md](docs/guides/release.md)). Новое пишется в «Не выпущено» в том же
PR, что и изменение.

## [Не выпущено]

## [0.1.1] — 2026-11-07 — порядок в репозитории

### Добавлено
- **Правила разработки:** `CONTRIBUTING.md` (ветки `main`/`dev`, Conventional Commits, DoD), шаблоны PR
  и issue.
- **Документация `docs/`:** архитектура (обзор, стек, данные, API, фронтенд, MAX), ADR 0001–0010,
  ТЗ продукта, глоссарий, ограничения, гайды (разработка, тесты, релиз), runbooks (MAX, деплой,
  обновление данных).
- **ТЗ фич** F-01 «Поделиться», F-02 ИИ-помощник, F-03 баллы ЕГЭ, F-04 сводка учителя, F-05 доп. баллы;
  бэклог всех идей `docs/specs/BACKLOG.md`.
- **Задачи** `docs/tasks/T-*.md`, скрипт `scripts/tasks.py`, рецепты `just tasks`, `tasks-next`,
  `tasks-check`, `check`, `migration`; дорожная карта.
- **CI:** запуск на `dev`, отмена устаревших прогонов, проверка задач; `.gitattributes` (LF).

### Изменено
- Ветки: `main` — актуальный код и автодеплой, `dev` — разработка; прежние версии — теги
  `prototype-v1`, `archive/olymp-rebuild`, `archive/main-new-stack`.
- README сокращён до одного экрана, подробности перенесены в `docs/`.

### Исправлено
- Документация утверждала, что во время пересборки базы API видит прежнюю версию; на деле
  `TRUNCATE` блокирует API примерно на минуту (исправление — T-064).
- gitleaks в CI падал на PR из-за прав токена.

## [0.1.0] — 2026-11-07 — новый стек, «Мои дипломы», MAX, стенд

### Добавлено
- **Стенд** https://ideafix.patissons.tech: автодеплой `main` после зелёного `ci` (образы в GHCR,
  выкатка по SSH, откат при сбое, проверка снаружи), Caddy на хосте, порты только на `127.0.0.1`,
  ежедневный дамп PostgreSQL — `infra/deploy/`.
- **«Мои дипломы»:** подбор льгот по дипломам с условиями вуза (степень, класс, годы, профиль/предмет),
  причины неподходящих строк.
- **Мини-приложение MAX:** вход по подписанным данным запуска, дипломы в профиле, кнопка «Назад»,
  ссылки `startapp`, бот с кнопкой «Открыть»; профили Docker `tunnel`, `https`, `bot`.

### Изменено
- Перенос на новый стек без изменения дизайна: uv-монорепозиторий (FastAPI, SQLAlchemy/Alembic,
  PostgreSQL, Redis, Dramatiq) и Next.js 16 + React 19; ответы API совпадают с прототипом на 2383 запросах.
- Лимит запросов считается по адресу посетителя, а не по серверу сайта.

## [prototype-v1] — 2026-09-24 — прототип

- Двусторонний поиск льгот («вуз → олимпиады», «олимпиада → вузы») по XLSX кампании 2026:
  SQLite, FastAPI, чистый JS. Сохранён тегом `prototype-v1`.

Параллельная перестройка с LLM-конвейером, движком правил и кабинетом учителя (до 2026-11-05)
не влита; сохранена тегом `archive/olymp-rebuild` — идеи из неё перенесены в бэклог.
