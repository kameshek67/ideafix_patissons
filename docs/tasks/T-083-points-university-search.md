## Цель
Во вкладке «Баллы» вузы были кнопками, и только те 7, для которых разобраны правила баллов за
достижения (`data/individual_achievements.csv`). Это читалось как полный список: «других вузов
нет». Выбор вуза должен быть таким же, как во вкладке «Вузы», — поиск по всем вузам базы, а про
вуз без разобранных правил нужно честно сказать.

## Что сделать
- [x] `ExtraPointsView`: вместо кнопок — `Combo` с поиском по всем вузам (`/v1/universities`,
      тот же кэш, что во вкладке «Вузы»). Сначала вузы с разобранными правилами, рядом — число правил.
- [x] Вуз без правил: сообщение «баллы этого вуза ещё не разобраны» и список вузов, где посчитать
      уже можно; правила для него не запрашиваются.
- [x] Тесты компонента.

## Критерии приёмки
- [x] Если открыть «Баллы», то в поиске вуза есть все вузы базы, а не только 7.
- [x] Если выбрать вуз без разобранных правил, то видно, что данных нет, а не «баллов нет».
- [x] Вёрстка проверена на 390×844.
- [x] `just check` зелёный (web: tsc, 88 тестов).

## Контекст
Комбобокс — `components/Combo.tsx`, пример — выбор вуза в `OlympApp.tsx`. Разбор правил остальных
вузов — отдельная задача по данным (ссылки на документы — `data/university_documents.json`).
