## Цель
TRUNCATE … CASCADE в ingest.py блокирует API ~1 мин и молча очистит будущие пользовательские таблицы с внешним ключом на данные.

## Что сделать
- [x] К демо: statement_timeout и lock_timeout в make_engine API; таймаут → 503 с Retry-After
- [x] Убрать CASCADE; тест «у пользовательских таблиц нет FK на таблицы сборки» (по схеме после миграций)
- [x] Решение: DELETE вместо TRUNCATE (`olymp_workers/tables.py`, и в `olymp-extra-points`); счётчики id — с начала последовательности, как RESTART IDENTITY; обновлены data.md, overview, ADR 0002, ранбуки

## Критерии приёмки
- [x] Во время сборки API отвечает (старые данные или быстрая ошибка 503, без зависания)
- [x] Тест на отсутствие FK из пользовательских таблиц и на порядок DATA_TABLES
- [ ] `just check` зелёный
