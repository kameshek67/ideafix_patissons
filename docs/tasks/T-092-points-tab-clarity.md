## Цель
Отзыв команды: во вкладке «Баллы» непонятно, зачем выбирать пункты из списка, и «зачем-то
выскакивает поле ввода». Ученик должен понимать: отметь, что у тебя есть, — увидишь сумму.

## Что найдено
- После галочки появлялись поле «Год получения» и выпадающий «Вид»; без года достижение не
  засчитывалось («укажи год получения»).
- Над списком из 16 правил ВШЭ — девять кнопок типов («Олимпиада» и «Олимпиады и конкурсы»
  рядом) и поиск.
- Сумма — в самом низу, под длинным списком; названия правил обрезаны на полуслове.

## Что сделать
- [x] Срок — текстом под правилом сразу («засчитывается, если получено в 2022–2026 годах»);
  галочка = «есть и получено в срок», год для подсчёта берётся внутри срока; поля года нет
- [x] Степень знака — кнопками, видными сразу; выбор степени отмечает достижение
- [x] Фильтр по типам и поиск — только у списков длиннее 30 правил (МИФИ)
- [x] Сумма над списком и прилипает при прокрутке; разбор — «Из чего сложилось»
- [x] Обрезанные названия — с многоточием; баллы на карточке — «+2 балла»

## Критерии приёмки
- [x] Тесты вкладки и `extraPoints` (срок, год, многоточие, нет фильтра у короткого списка)
- [x] Проверено в браузере (375 px) на данных стенда: ВШЭ, ГТО + аттестат → 5 из 10
- [x] `just check` зелёный (CI)
