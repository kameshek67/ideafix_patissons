## Цель
До 640 px скрыты «Кому», класс и предмет ЕГЭ — главное для решения школьника.

## Что сделать
- [x] В первой колонке таблиц под названием олимпиады — строка «Победителям · 10–11 кл. · ЕГЭ инф. ≥ 75» (только на узкой ширине)
- [x] «Балл 75» всегда с предметом
- [x] Проверить на 360 и 390 px во всех трёх вкладках

## Критерии приёмки
- [x] На 360 px видны все условия строки без горизонтальной прокрутки
- [ ] `just check` зелёный

## Контекст
По итогам ревью 2026-11-07.

## Журнал

- 2026-11-08: `conditionsLine` (`lib/conditions.ts`) собирает «Только победители · 11 класс · ЕГЭ математика ≥85» из данных строки; порог без предмета не показывается без пометки «ЕГЭ». Строка идёт второй под названием в первой колонке трёх таблиц (направление, вуз в результатах олимпиады, подробности «Дипломов») и скрыта с 640 px (`sm:hidden`), где колонки видны. Проверено вручную на 360 px (вкладка «Вузы», ВШЭ, «Прикладная математика и информатика»). Сама таблица на телефоне по-прежнему прокручивается по горизонтали внутри карточки (остальные колонки), условия при этом видны сразу. Вкладки «Олимпиады» и «Дипломы» используют тот же компонент: проверены только тестами.
