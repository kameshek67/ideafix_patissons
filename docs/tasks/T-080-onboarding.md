## Цель
Новый пользователь — особенно в мини-приложении MAX — сразу понимает три сценария «Олимпа»
и за один шаг попадает к добавлению своего диплома.

## Что сделать
- [x] Макет: плагин Figma, рисующий раздел «03 · Онбординг · 430» рядом с доской «Идея фикс»
      (`design/figma-onboarding/`) — REST и MCP Figma только читают файлы.
- [x] `apps/web/src/components/Onboarding.tsx`: три экрана («Выбери вуз → узнай олимпиады»,
      «Олимпиада → куда с ней поступить», «Мои дипломы → все льготы сразу»), свайп
      (лента со snap-прокруткой) или «Далее», «Пропустить», белая шторка с прогрессом и кнопками.
- [x] `apps/web/src/lib/onboarding.ts`: показывать один раз (флаг на устройстве), не показывать
      при запуске ссылкой `startapp=…`, `?onboarding` — показать принудительно.
- [x] В `OlympApp`: «Добавить диплом» открывает форму на вкладке «Дипломы», остальное — «Вузы».
- [x] MAX: кнопка «Назад» в шапке — на предыдущий шаг; на третьем экране «сохранится в профиле MAX»,
      в браузере — «на этом устройстве».

## Критерии приёмки
- [x] Если запустить сайт впервые, то показывается онбординг; после «Пропустить» или последнего
      шага он больше не появляется.
- [x] Если открыть по `just max-link --start diplomas`, то онбординга нет, открыта вкладка «Дипломы».
- [x] Если на последнем шаге нажать «Добавить диплом», то открыта форма диплома.
- [x] Вёрстка проверена на 390×844, 375×667 и на десктопе (карточка 430 по центру).
- [x] Остальные экраны не изменились (сценарий сверки дизайна).
- [x] `just check` зелёный.

## Контекст
Макет — раздел «03 · Онбординг · 430» (плагин в `design/figma-onboarding/`). Токены и классы —
`apps/web/src/app/styles.css` (`.btn-primary`, `.btn-secondary`, `.badge-*`). Кнопка «Назад» MAX —
`useMaxBackButton` из `MaxProvider.tsx`.
