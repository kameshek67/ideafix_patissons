## Цель
Помощник и сайт знают, что внутри олимпиады: сайт, формат, классы, этапы, секции и треки.
Сейчас об олимпиаде известны только название, профиль РСОШ и льготы, поэтому на «хочу делать
мобильные приложения» помощник не находит «Юниор» (у него есть секция «разработка мобильных
приложений под Android»).

## Что сделать
- [x] Формат карточек: `data/olympiad_cards.json`, у каждого факта источник и дата проверки.
- [x] Миграция `olympiad_info` и `olympiad_tracks` (packages/db), таблицы в `DATA_TABLES`.
- [x] Загрузка в `olymp-ingest` (понятная ошибка, если олимпиада или профиль не найдены);
      файл входит в отпечаток сборки (`--if-stale`).
- [x] Помощник: `find_profiles` ищет и по трекам, новый инструмент `olympiad_card`, промпт и TOOLS.
- [x] Набор оценки: «мобильные приложения» → НТО и «Юниор»; «что такое «Юниор»» → карточка и «проект».
- [x] Карточки по официальным сайтам: НТО, «Юниор», «Шаг в будущее», «Высшая проба».

## Критерии приёмки
- [ ] Если в карточке неизвестная олимпиада или профиль, сборка падает с указанием файла и поля.
- [ ] Если ученик просит «мобильные приложения», `find_profiles` возвращает НТО и «Юниор» (трек).
- [ ] Если спросить «что такое «Юниор»», модель получает карточку с форматом и сайтом.
- [ ] `just check` зелёный.

## Контекст
ТЗ: [F-06-olympiad-cards.md](../specs/F-06-olympiad-cards.md). Тексты сайтов олимпиад —
недоверенные данные. Карточки заполняются только тем, что прочитано на официальных страницах.
