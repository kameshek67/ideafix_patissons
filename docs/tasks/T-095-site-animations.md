## Цель
Интерфейс сайта выглядел статичным: вкладки, списки и окна появлялись рывком. Нужны короткие
анимации появления и отклика, но только на сайте — в мини-приложении MAX интерфейс остаётся
спокойным, как в нативных экранах MAX.

## Что сделать
- [x] Блок анимаций в конце `styles.css`: заголовок, переключение вкладок, выпадающие списки,
      карточки и строки списков лесенкой, строки таблиц, чипы, кнопки, шторки и окна.
- [x] Анимации только вне MAX: селектор `html:not([data-max]):not([data-max-boot])`; `data-max-boot`
      ставит загрузчик Bridge в `<head>` до первой отрисовки, чтобы анимации не мелькнули при запуске.
- [x] Уважать `prefers-reduced-motion: reduce` — тогда анимаций нет.
- [x] Классы `sheet-backdrop`/`sheet-panel` у окон «О приложении» и «Диплом».

## Критерии приёмки
- [x] Если открыть сайт в браузере и переключить вкладку, то содержимое плавно выезжает снизу.
- [x] Если открыть сайт как мини-приложение MAX, то анимаций нет.
- [x] Вёрстка проверена на 390×844.
- [x] `npm run lint` и тесты фронтенда зелёные (116).
