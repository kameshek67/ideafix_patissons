## Потоки данных

**Сборка (редко, раз в сезон или после правки парсера).** `olymp-ingest` читает 17 листов XLSX,
нормализует названия олимпиад и профилей, раскладывает текстовые перечисления в строки,
выводит строки из правил «по профилю», строит связи и полнотекстовый индекс и записывает всё
**одной транзакцией**. Таблицы очищаются `DELETE`, поэтому API во время сборки отвечает прежними данными (T-064). Время сборки (`meta.built_at`)
входит в ключи кэша — после пересборки старый кэш перестаёт использоваться. Подробно — [data.md](data.md).

**Запрос пользователя.** Браузер → Next.js `/api/v1/*` → FastAPI `/v1/*` → (Redis) → PostgreSQL.
Ответ — таблицы льгот со ссылкой на источник. Сайт и API на одном origin, CORS разрешает чужим
сайтам только GET.

**Пользователь MAX.** MAX открывает сайт с подписанными данными запуска (`initData`). Сайт
передаёт их в заголовке `X-Max-Init-Data`, API проверяет подпись токеном бота и узнаёт
пользователя. Дипломы хранятся на сервере (`max_users`, `user_diplomas`); вне MAX — в
`localStorage`. Подробно — [max-mini-app.md](max-mini-app.md).

## Границы модулей

Проверяются `lint-imports` в CI (контракты в `pyproject.toml`):

- `olymp_domain` — чистый код: не импортирует БД, API, воркеры, не ходит в сеть.
- `olymp_api.modules.{catalog,search,achievements}` независимы друг от друга; общее — в
  `olymp_api/*.py`.
- `olymp_api.modules.assistant` — верхний слой: вызывает сервисы этих модулей, они о нём не знают.
- `olymp_api` не зависит от `olymp_workers`.

## Окружения

| Окружение | Как | Адреса |
|---|---|---|
| Разработка | `just up` (инфраструктура в Docker) + `just api` + `just web` | сайт :3000, API :8000 |
| Весь стек локально | `docker compose up --build -d` | сайт :8080, API :8000 |
| **Стенд (прод)** | автодеплой `main` после зелёного `ci` ([infra/deploy](../../infra/deploy/README.md)) | https://ideafix.patissons.tech |
| Запасное демо без сервера | профиль `tunnel` (Cloudflare quick tunnel) | `https://*.trycloudflare.com` |
| Другой свой сервер | профиль `https` (Caddy + Let's Encrypt), `OLYMP_DOMAIN` | `https://<домен>` |

## Наблюдаемость

Логи API — JSON (structlog) с `request_id` (заголовок `x-request-id`). Метрики Prometheus —
`/metrics` (наружу через сайт не проксируется). Проверки — `/healthz` (жив) и `/readyz`
(база доступна и собрана).
