# API

Swagger — `http://localhost:8000/docs` (через сайт — `/docs`). Контракт — [`docs/openapi.json`](../openapi.json),
генерируется из кода (`just openapi`); фронтенд берёт типы из `packages/api-client`.

## Соглашения

- Публичные эндпоинты — под `/v1`; служебные `/healthz`, `/readyz`, `/metrics` — без версии.
- Ошибки — RFC 9457, `application/problem+json` (`olymp_api/errors.py`).
- Каждый ответ несёт `x-request-id` (берётся из запроса или создаётся).
- Ответы поиска кэшируются в Redis; ключ включает `meta.built_at` — после пересборки базы
  кэш обновляется сам. Без Redis кэш и лимит работают в памяти процесса.
- Лимит — 600 запросов в минуту с IP (`OLYMP_RATE_LIMIT_*`); 429 + `Retry-After`.
- CORS: чужим origin — только GET. Запись (`PUT /v1/me/*`, `POST /v1/shares`) — только с самого сайта.
- Данные пользователя MAX — заголовок `X-Max-Init-Data` (подписанные данные запуска);
  без токена бота на сервере эти эндпоинты отвечают 503.
- Ломающие изменения контракта — только с новой версией пути или с обратной совместимостью
  (новые поля можно добавлять, удалять и переименовывать — нельзя).

## Эндпоинты

| Метод | Назначение |
|---|---|
| `GET /healthz`, `GET /readyz` | жив ли сервис / доступна ли собранная база |
| `GET /v1/stats` | счётчики охвата базы, статистика по вузам, топ олимпиад, отчёт сборки (сайт их не показывает — для презентации и проверок) |
| `GET /v1/regions` | Москва / Санкт-Петербург / Регионы |
| `GET /v1/universities?region=&q=` | вузы с числом направлений и льгот |
| `GET /v1/programs?university_id=&q=` | направления вуза |
| `GET /v1/olympiads?q=&featured=&limit=` | автокомплит по названиям и сокращениям (+ число профилей) |
| `GET /v1/olympiads/{id}/profiles` | профили олимпиады со счётчиками БВИ / 100 баллов / вузов |
| `GET /v1/search/by-program?program_id=` | строки таблиц по типам льгот, примечания, олимпиады, источники |
| `GET /v1/search/by-olympiad?q=&olympiad_id=&profile_id=&university_id=&region=&benefit_type=` | обратный поиск: список вузов, а с `university_id` — все строки выбранного вуза |
| `GET /v1/assistant/config` | доступен ли ИИ-помощник и подсказки |
| `POST /v1/assistant/chat` | ответ помощника потоком `text/event-stream`: `status`, `delta`, `entities`, `sources`, `done`, `error`. Сайт ходит через `/api/assistant/chat` ([F-02](../specs/F-02-ai-chat.md)) |
| `POST /v1/assistant/feedback` | оценка ответа: только счётчик в метриках |
| `GET /v1/achievements/olympiads/{id}` | олимпиада для формы диплома: ключ и профили без мусора разбора таблиц |
| `GET /v1/achievements/match?diploma=…&diploma=…&benefit_type=&university_id=` | «Мои дипломы»: итоги по каждому диплому, вузы, а с `university_id` — строки вуза |
| `GET /v1/extra-points/universities?admission_year=` | вузы, у которых в базе есть баллы за индивидуальные достижения (ГТО, аттестат…) |
| `GET /v1/extra-points/universities/{id}?admission_year=` | правила вуза: баллы, условия, лимит суммы, цитата из документа |
| `POST /v1/extra-points/score` | сколько баллов за отмеченные достижения получит школьник в вузе (с лимитом); ничего не сохраняется |
| `GET /v1/max/config` | настроен ли вход через MAX, имя бота, годы, за которые дипломы действуют |
| `GET /v1/me/diplomas`, `PUT /v1/me/diplomas` | дипломы пользователя MAX (заголовок `X-Max-Init-Data` — подписанные данные запуска) |
| `POST /v1/shares` | ссылка «Поделиться» на карточку направления, выдачу по олимпиаде или итоги дипломов: снимок по стабильным ключам, тот же экран — тот же токен ([F-01](../specs/F-01-share.md)) |
| `GET /v1/shares/{token}` | что открыть по ссылке: тип экрана, фильтр и актуальные id объектов снимка; 404 — ссылки нет или она устарела |

```bash
curl "http://localhost:8000/v1/search/by-olympiad?q=высшая%20проба&region=Москва"
curl "http://localhost:8000/v1/olympiads?q=нто"
curl "http://localhost:8000/v1/search/by-program?program_id=135"
```

`by-olympiad` возвращает точные итоги (`total_universities`, `total_programs`) отдельным
агрегатом, а подробные строки — с лимитом, поэтому счётчики не «плывут» на больших олимпиадах.

### «Мои дипломы»: как подбираются льготы

Диплом передаётся строкой `ключ_олимпиады.ключ_профиля.степень.класс.год`, например
`всероссийскаяолимпиадашкольниковвысшаяпроба.математика.w.11.2025` (`-` — профиль не указан,
`w` — победитель, `p` — призёр, `0` — класс или год не указаны). Ключи — нормализованные
названия, а не id: id меняются при пересборке базы, а сохранённые дипломы должны оставаться
верными. Ключи отдаёт `/v1/achievements/olympiads/{id}`.

Строки льгот берутся по тем же связям «льгота — олимпиада — профиль», что и в обратном поиске,
а условия вуза проверяет `packages/domain/src/olymp_domain/diplomas.py`:

* **профиль** — строка с профилем подходит только диплому этого профиля. Если профиля в строке
  нет, но указан предмет (так часто у ВсОШ), сравнивается предмет, причём «английский язык»
  совпадает с «иностранным языком». Если нет ни профиля, ни предмета, строка показывается
  с пометкой «проверить»: соответствие профиля направлению нужно сверить с правилами вуза;
* **«Кому»** — «только победители» не подходят призёрам; «победители и призёры», «призёры»
  и пустая колонка подходят обоим; строки «для членов сборных» обычному диплому не подходят;
* **класс** — «11 класс», «10, 11 класс», «победители и призёры (10–11 класс)»: диплом за другой
  класс не подходит (если класс не указан, строка не отбрасывается);
* **годы** — «2023, 2024» или сезоны «2024/25» (засчитывается год окончания). Если вуз годы
  не указал, действует общее правило: в кампанию 2026 года — олимпиады 2023–2026 годов.

Направление считается по лучшей льготе (БВИ, затем 100 баллов, затем остальные), а сколько строк
не подошло и почему, показывается под итогами. Порог ЕГЭ, которым диплом нужно подтвердить,
выводится в таблице, но не проверяется: баллов ЕГЭ ученик в форму не вводит.

## Сверка с прототипом

Ответы API совпадали с API прототипа (тег `prototype-v1`) на 2383 запросах. Скрипт
`scripts/compare_with_prototype.py` (`just compare`) сравнивает все направления, олимпиады
с профилями и фильтрами, свободный ввод и полнотекстовый поиск; прототип должен работать
на :8000 (`git worktree add ../olymp-prototype prototype-v1 && cd ../olymp-prototype && docker compose up -d`).
Сверка нужна только при правках поиска, которые не должны менять результат.
