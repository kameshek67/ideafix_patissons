# F-01. «Поделиться» и стабильные ссылки

- Приоритет: P0
- Статус: готово к работе
- Дата: 2026-11-07
- Требования продукта: FR-22, FR-23

## Зачем
Школьник показывает результат другу, родителю или учителю, а учитель отправляет выдачу в
беседу класса. Для MAX это главный вирусный механизм: каждое «Поделиться» приводит нового
пользователя в мини-приложение. Открытие экранов по `startapp` уже есть, но нет кнопки и
отправки, а ссылки с id ломаются после пересборки базы (ADR 0007).

## Пользовательские истории
- Как школьник, я хочу отправить другу карточку направления, чтобы он увидел те же олимпиады.
- Как школьник, я хочу поделиться итогами своих дипломов с учителем или родителем.
- Как учитель, я хочу отправить в беседу класса выдачу по олимпиаде («вот куда даёт НТО по ИИ»).
- Как получатель, я открываю ссылку и сразу вижу тот же экран — в MAX или в браузере.

## Что можно расшарить

| Объект | Где кнопка | Что увидит получатель |
|---|---|---|
| Карточка направления | шапка `ProgramView` | вуз, направление, таблицы льгот (с фильтром по типу льготы, если он был выбран) |
| Выдача по олимпиаде | над `OlympiadResults` и в `UniversityBenefits` | олимпиада, профиль, список вузов (или льготы выбранного вуза) |
| Итоги дипломов | над итогами в `DiplomasView` | **только для чтения**: дипломы отправителя и их итоги; кнопка «Добавить эти дипломы себе» скрыта, вместо неё «Проверить свои дипломы» |

## Поведение

**Кнопка.** Иконка «поделиться» + подпись «Поделиться» в стиле существующих кнопок-чипов
(без новых UI-библиотек). На телефоне — в правом верхнем углу карточки.

**Отправка:**
1. В MAX: `WebApp.shareMaxContent({ text, link })` → системный выбор чата. Ответ `cancelled` — без
   сообщений. Если метод недоступен — `shareContent`, если и его нет — как в браузере.
2. В браузере: `navigator.share({ title, text, url })`, иначе копирование в буфер и тост
   «Ссылка скопирована».
3. Тактильный отклик `success` после отправки (на телефоне в MAX).

**Текст сообщения** (до 200 символов, без персональных данных):
- направление: «НИУ ВШЭ · Прикладная математика и информатика — 54 олимпиады дают БВИ. Открыть в «Олимпе»:»
- олимпиада: «Высшая проба (математика) — БВИ в 23 вузах, 100 баллов в 31. Открыть:»
- дипломы: «Мои дипломы дают БВИ в 12 вузах и 100 баллов в 18. Посмотри:»

**Ссылки.** Две формы одного токена:
- MAX: `https://max.ru/<бот>?startapp=s_<token>`
- браузер: `https://<сайт>/s/<token>` → страница открывает приложение на нужном экране.
Если бот не настроен (`/v1/max/config` → `enabled: false`), используется только браузерная ссылка.

**Открытие.** `OlympApp` при `start_param` вида `s_<token>` или маршруте `/s/<token>`
запрашивает снимок и открывает экран. Если токен не найден — тост «Ссылка устарела» и
стартовый экран. Старые `startapp=program-<id>` / `olympiad-<id>` / `diplomas` продолжают работать.

## Данные и API

Снимок хранит **стабильные ключи** (не id), чтобы ссылка жила после пересборки базы.

```
share_links(
  token        text primary key,    -- 10 символов base62, crypto-random
  kind         text not null,       -- 'program' | 'olympiad' | 'diplomas'
  payload      jsonb not null,      -- см. ниже, ≤ 4 КБ
  created_at   timestamptz default now(),
  opened_count integer default 0,
  last_opened  timestamptz
)
```

| kind | payload |
|---|---|
| `program` | `{university: <short_name>, program_key: <squash названия+коды>, benefit_type?}` |
| `olympiad` | `{olympiad_key, profile_key?, university?: <short_name>, benefit_type?, region?}` |
| `diplomas` | `{diplomas: ["ключ.профиль.w.11.2025", …]}` (≤ 20) |

Сборка базы таблицу не трогает. Для `program` нужен стабильный ключ направления: добавить
в `programs` колонку `stable_key` (вуз + нормализованное имя + коды), вычисляемую при сборке;
уникальность проверяет тест сборки.

| Метод | Путь | Запрос | Ответ |
|---|---|---|---|
| POST | `/v1/shares` | `{kind, payload}` | `201 {token, web_url, max_url?}` |
| GET | `/v1/shares/{token}` | — | `200 {kind, payload, resolved}`, где `resolved` — актуальные id (`program_id`, `olympiad_id`, `profile_id`, `university_id`) или `null`, если сущность пропала; `404` — нет токена |

- POST идемпотентен: одинаковый `kind+payload` (хэш) → тот же токен.
- Лимит: 30 POST в минуту с IP; валидация payload схемой Pydantic; ключи проверяются по базе.
- Новый модуль API `modules/sharing` (контракт независимости в `pyproject.toml`).

## Безопасность и персональные данные
- В снимке нет id пользователя MAX и имени; дипломы — без привязки к человеку.
- Токен непредсказуем (`secrets.token_urlsafe` → base62, 10 символов); перебор ограничен лимитом.
- Страница `/s/<token>` не индексируется (`noindex`).

## Критерии приёмки
- [ ] На карточке направления, выдаче по олимпиаде и итогах дипломов есть «Поделиться».
- [ ] В MAX открывается выбор чата; получатель по кнопке в сообщении попадает на тот же экран.
- [ ] В браузере работает `navigator.share` или копирование ссылки; ссылка открывает тот же экран.
- [ ] После `docker compose run --rm migrate olymp-ingest` (пересборка) старые ссылки открывают те же объекты.
- [ ] Итоги дипломов у получателя — только чтение, его собственные дипломы не меняются.
- [ ] Несуществующий токен → тост «Ссылка устарела», без ошибки в консоли.
- [ ] `startapp=diplomas|program-<id>|olympiad-<id>` по-прежнему работают.

## Тесты
- API: создание и чтение снимка, идемпотентность, 404, валидация payload, `resolved` после пересборки
  (в тесте: две сборки в одной временной базе, токен из первой открывается во второй).
- Домен: функция стабильного ключа направления (уникальность на настоящей сборке).
- Web: `buildShareText`, выбор способа отправки (MAX → share API → буфер) с моками; открытие по `s_<token>`.
