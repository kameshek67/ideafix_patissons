# Бэклог фич

Все идеи фич — со скрина команды, из прежнего видения (`archive/olymp-rebuild`) и из ревью
2026-11-07. **Решение о том, что делать к демо, ещё не принято** — команда выбирает отсюда.
Когда идею берут в работу, для неё пишется ТЗ `F-NN` и задачи `T-NNN`.

Ценность — для пользователя и жюри; трудоёмкость — в человеко-днях с тестами (оценки ревью).
