# F-04. Сводка для учителя

- Приоритет: P2
- Статус: нужен выбор варианта хранения (решение — ниже, требует подтверждения команды)
- Дата: 2026-11-07
- Требования продукта: FR-40

## Зачем
Учитель или классный руководитель хочет видеть, кто из учеников уже «закрыл» поступление
олимпиадами и кому не хватает баллов ЕГЭ — чтобы советовать олимпиады и не терять сильных
ребят. Сферум переехал в MAX, поэтому учитель уже там.

## Главный вопрос: где хранятся данные класса

Дипломы и баллы учеников — персональные данные несовершеннолетних (152-ФЗ). Учитель не
должен вводить их за учеников и хранить без согласия.

| Вариант | Как | Плюсы | Минусы |
|---|---|---|---|
| **A. Ученики сами делятся с учителем** (рекомендуется) | Учитель создаёт «класс» и получает ссылку-приглашение `startapp=class_<token>`. Ученик открывает её в MAX, видит «Поделиться дипломами с учителем Ивановой И. И.?» и соглашается. Учитель видит живые данные ученика, пока тот не отзовёт доступ | Согласие явное, данные у ученика, всегда актуально | Нужны таблицы классов и доступов, ученики должны быть в MAX |
| B. Учитель собирает ссылки F-01 | Ученики присылают «Поделиться итогами», учитель сохраняет снимки в свой список | Почти ничего нового на сервере | Снимки устаревают, нет баллов ЕГЭ, ручная работа |
| C. Учитель вводит данные сам | Форма «ученик + дипломы» в профиле учителя | Просто сделать | ПДн без согласия, двойной ввод — не делаем |
| D. Импорт из Сферума/MAX | API школ | Идеально | Публичного API нет — после хакатона |

**Предложение:** вариант A, а для демо — упрощённая версия (без отзыва доступа в интерфейсе,
только удаление ученика учителем).

## Поведение (вариант A)
- Учитель: «Дипломы» → «Я учитель» → «Создать класс» (название, например «11Б») → ссылка-приглашение
  и кнопка «Отправить в беседу класса» (F-01, MAX share).
- Ученик: открывает приглашение → экран согласия (кто, что увидит: дипломы, баллы ЕГЭ, итоги) →
  «Разрешить» / «Не сейчас».
- Сводка класса: таблица «ученик (имя из MAX) · дипломов · вузов с БВИ · с 100 баллами ·
  подтверждено ЕГЭ · не хватает» + раскрытие ученика до его итогов. Выгрузка CSV.
- Ученик в своём профиле видит «Мои учителя» и может отозвать доступ.

## Данные и API (эскиз)
```
classes(id, owner_user_id, title, invite_token, created_at)
class_members(class_id, user_id, consent_at, revoked_at)
```
`POST /v1/classes`, `GET /v1/classes`, `GET /v1/classes/{id}/summary`, `POST /v1/classes/join/{token}`,
`DELETE /v1/classes/{id}/members/{user_id}`, `GET/DELETE /v1/me/teachers`. Все — только для
пользователей MAX (initData). Новый модуль API `classroom`.

## Безопасность и персональные данные
- Доступ учителя — только к членам своих классов с действующим согласием.
- Согласие хранится с датой; отзыв мгновенно закрывает доступ.
- Учитель видит имя из MAX, но не id; данные класса в LLM не передаются.
- Текст согласия и политика обработки ПДн — отдельная задача (юридические документы).

## Критерии приёмки (для демо)
- [ ] Учитель создаёт класс и отправляет приглашение в чат.
- [ ] Ученик принимает приглашение с экраном согласия.
- [ ] Учитель видит сводку класса с итогами и баллами ЕГЭ (если F-03 готова).
- [ ] Ученик видит учителя в «Мои учителя» и может отозвать доступ; после отзыва учитель его не видит.

## Тесты
API: доступ только к своему классу, отзыв согласия, приглашение по неверному токену.
Web: экран согласия, сводка.

## Вне рамок
Роли школы и завуча, импорт из Сферума, уведомления учителю.

## Открытые вопросы

- Нужен ли текст согласия, проверенный юристом, для демо (предлагается: шаблон с пометкой «демо»).
