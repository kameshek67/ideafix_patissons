# F-05. Доп. баллы: ГТО, медаль, конкурсы (индивидуальные достижения)

- Приоритет: P3 (после хакатона); к демо — только исследование
- Статус: исследование
- Дата: 2026-11-07
- Требования продукта: FR-15

## Зачем
Кроме льгот за олимпиады, вузы начисляют баллы за индивидуальные достижения (ИД): аттестат
с отличием или медаль, золотой знак ГТО, итоговое сочинение, волонтёрство, олимпиады и
конкурсы, не дающие БВИ. Иногда эти баллы решают поступление на бюджет.

## Проблема
В исходном XLSX таких данных нет, кроме листа «УрФУ +4 балла». Без данных фичу делать нельзя.

## Что сделать к демо (T-050)
1. Найти первоисточники: общий порядок приёма (Минобрнауки) задаёт перечень ИД и общий
   лимит баллов, вузы публикуют свои таблицы ИД в правилах приёма. Проверить действующие
   на кампанию 2026 года документы и записать ссылки.
2. Для 5 вузов из базы (ВШЭ, МФТИ, ИТМО, МГУ, УрФУ) вручную собрать таблицу ИД
   «достижение → баллы → условия» в `data/individual_achievements.csv` со ссылкой на документ
   у каждой строки.
3. Предложить модель данных и экран — дописать это ТЗ до статуса «готово к работе».

## Эскиз решения (после исследования)
- Таблица `individual_achievements(university_id, kind, points, conditions, source_url)`,
  `kind` из справочника (`medal`, `gto_gold`, `essay`, `volunteer`, `olympiad_non_bvi`, …).
- В «Дипломах» — блок «Другие достижения» (галочки: медаль, ГТО, сочинение…); в итогах по
  вузу — «+N баллов за достижения (не больше лимита вуза)».

## Критерии готовности исследования
- [ ] Ссылки на действующие документы о порядке начисления ИД.
- [ ] CSV по 5 вузам с источником у каждой строки.
- [ ] Обновлённое ТЗ с моделью данных и макетом экрана.
