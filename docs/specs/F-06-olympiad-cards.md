# F-06. Справочник олимпиад: карточки и треки

- Приоритет: P1
- Статус: в работе (T-082)
- Дата: 2026-11-08
- Требования продукта: FR-02 (подбор олимпиад под интересы)

## Зачем
О льготах мы знаем всё, что пишут вузы, а об олимпиадах — только название, профиль РСОШ,
уровень и счётчики. Секций, формата, классов и сайта в базе нет. Пример: у конкурса «Юниор»
в базе два профиля («инженерные науки», «естественные науки»), а секция «разработка мобильных
приложений под Android» есть только на сайте конкурса. Поэтому на «хочу делать мобильные
приложения» помощник «Юниор» не находит. Промптом это не лечится: факта нет в данных.

## Пользовательские истории
- Как школьник, я хочу назвать увлечение и получить олимпиады, у которых есть секция про него,
  чтобы не пропустить конкурс, чей профиль называется шире.
- Как школьник, я хочу спросить «что такое «Юниор», как он проходит», и получить формат, классы
  и ссылку на официальный сайт.

## Данные
`data/olympiad_cards.json` — карточки, которые проходят ревью в PR:

```json
{
  "olympiad": "Всероссийский конкурс научных работ школьников «Юниор»",
  "site_url": "https://olymp.mephi.ru/junior",
  "summary": "…",
  "grades": "9–11",
  "format": ["задачи", "проект", "защита"],
  "stages": ["отборочный: тезисы работы", "финал: письменная часть и защита проекта"],
  "source_url": "https://…", "checked": "2026-11-08",
  "tracks": [
    {"name": "…", "profile": "инженерные науки", "topics": ["…"],
     "source_url": "https://…", "checked": "2026-11-08"}
  ]
}
```

- `olympiad` — `canonical_name` из таблицы `olympiads`; `profile` — название профиля этой
  олимпиады (сравнение по `squash`). Не нашлось — сборка падает с файлом и полем.
- `format` — из списка: задачи, проект, защита, командная, тезисы. Этапы — без точных дат:
  помощник их не называет.
- Трек привязан к профилю РСОШ. **Льготы у трека те же, что у профиля**: вузы дают их по
  профилю из перечня, поэтому в `find_profiles` трек показывается вместе с профилем и его льготами.
- Источник и дата проверки обязательны у карточки и у каждого трека.
- Таблицы `olympiad_info` и `olympiad_tracks` входят в `DATA_TABLES`; файл входит в отпечаток
  сборки, поэтому правка карточки пересобирает базу (`--if-stale`).

## Помощник
- `find_profiles` сопоставляет тему с названием профиля, а также с названием и темами трека
  (по основам слов, `olymp_domain.interests`). В строке результата — `track`, если нашлось по нему.
- `olympiad_card(olympiad_id)` — карточка для вопросов «что это, как проходит, где сайт».
  Принимает только id из поиска в этом же ответе. Нет карточки — «нет данных», без выдумки.
- Сервер сам показывает ссылку на официальный сайт как источник; модель свою не подставляет.

## Безопасность
Тексты сайтов — недоверенные данные: в карточки попадает только то, что проверил человек в PR;
инструкции из текстов не исполняются.

## Критерии приёмки
- [ ] Карточка с неизвестной олимпиадой или профилем останавливает сборку понятной ошибкой.
- [ ] «мобильные приложения» → в `find_profiles` есть НТО и «Юниор» (трек).
- [ ] `olympiad_card` для «Юниора» отдаёт формат с проектом, сайт и источник.
- [ ] Правка `olympiad_cards.json` меняет отпечаток сборки.

## ИИ-черновики (T-094)
`just ai-cards sites` берёт официальные сайты из перечня РСОШ (rsr-olymp.ru) и сопоставляет их
с олимпиадами базы: сначала точное название, затем «якоря» справочника, затем вхождение названия,
если оно однозначно. `just ai-cards draft --top N` для олимпиад без карточки скачивает главную
страницу и до двух страниц «об олимпиаде», модель извлекает поля карточки **с дословной цитатой
на каждый факт**, а код проверяет цитату по скачанному тексту:
- описание без подтверждённой цитаты — карточки нет; классы — только если числа есть в цитате;
- формат — только из списка, этап «регистрация» не этап; трек — только если его название есть на
  странице, профиль — у олимпиады в базе, и это не тот же профиль другими словами;
- сайты на скриптах, с сертификатом Минцифры (нужен `infra/certs`), без https — пропускаются.
У карточки `"review": "ai"`; файл дописывается в конец, ручные карточки не переписываются.
Человек читает черновики в PR так же, как ручные: льгот и уровней в описании быть не должно.

## Вне рамок
Живой веб-поиск в чате, ответы модели «из головы» о треках и сроках, векторный поиск (на сотни
карточек хватает поиска по основам слов). Следующей задачей: воркер скачивает официальные сайты
топ-50 олимпиад, LLM делает черновики карточек, человек проверяет их в PR. Страница олимпиады
на сайте (описание, треки, ссылка) — после этой задачи.
