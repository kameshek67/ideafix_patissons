# ТЗ фич

ТЗ описывает **что и зачем** (поведение, данные, контракт, критерии приёмки), а не построчную
реализацию. Задачи (`docs/tasks/`) ссылаются на ТЗ и режут его на куски по 0.5–1 дню.

| ID | Фича | Приоритет | Статус | Задачи |
|---|---|---|---|---|
| [F-01](F-01-share.md) | «Поделиться» и стабильные ссылки | P0 | готово к работе | T-010…T-014 |
| [F-02](F-02-ai-chat.md) | ИИ-помощник вместо планировщика | P0 | готово к работе (провайдер — открытый вопрос) | T-020…T-026 |
| [F-03](F-03-ege-check.md) | Проверка баллов ЕГЭ в «Дипломах» | P0 | готово к работе | T-030…T-033 |
| [F-04](F-04-teacher-summary.md) | Сводка для учителя | P2 | нужен выбор варианта хранения | T-040 |
| [F-05](F-05-extra-points.md) | Доп. баллы (ГТО, медаль, конкурсы) | P3 | исследование → реализация | T-050…T-054 |

Приоритеты: **P0** — нужно к демо, **P1** — желательно к демо, **P2** — если останется время,
**P3** — после хакатона.

Новое ТЗ — копия [TEMPLATE.md](TEMPLATE.md), следующий свободный номер, строка в таблице выше.
