# 0006. Мини-приложение MAX: вход по initData, данные на сервере

- Статус: принято
- Дата: 2026-11-07

## Контекст
Школьники и учителя переходят из Сферума в MAX. Мини-приложение должно узнавать пользователя
без логина и пароля и хранить его дипломы между устройствами.

## Решение
- Сайт и мини-приложение — один код. Bridge MAX загружается только при запуске из MAX.
- Пользователя определяют подписанные данные запуска (`initData`): API проверяет их HMAC
  с токеном бота. Сессий и cookie нет — заголовок `X-Max-Init-Data` идёт с каждым запросом.
- Дипломы пользователя MAX хранятся на сервере, вне MAX — в `localStorage`.
- Без токена бота работает всё, кроме синхронизации.

## Альтернативы
- Своя авторизация (email, пароль) — лишнее трение для школьника.
- Хранить всё только на устройстве — данные пропадают при смене телефона.

## Последствия
`max_users` — персональные данные: не логируем, не передаём третьим лицам и в LLM. У каждой
фичи с MAX должен быть запасной путь в браузере.

## Когда пересмотреть
Если понадобится вход вне MAX (родители, учителя с компьютера) — добавить вход через VK ID или Госуслуги.
