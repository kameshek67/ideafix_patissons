# 0007. Дипломы и ссылки хранятся стабильными ключами, а не id

- Статус: принято
- Дата: 2026-11-07

## Контекст
id олимпиад, профилей и направлений меняются при каждой пересборке базы ([0002](0002-data-from-xlsx.md)).
Сохранённый диплом или ссылка с id после пересборки указали бы на другую сущность.

## Решение
- Диплом — строка `ключ_олимпиады.ключ_профиля.степень.класс.год`. Ключи — нормализованные
  названия (`squash_key`), их отдаёт `/v1/achievements/olympiads/{id}`.
- Всё, что живёт дольше одной сборки (данные пользователя, ссылки «Поделиться», сохранённые
  выборки учителя), использует ключи или серверный снимок, а не id.

## Альтернативы
Сохранять id и пересчитывать их при сборке — нужна таблица соответствий старых и новых id.

## Последствия
Ссылки `startapp=program-<id>` и `olympiad-<id>` нестабильны — их заменяет механизм из
[F-01](../specs/F-01-share.md). Если олимпиаду переименуют в источнике, её ключ изменится —
такие случаи закрываются алиасами в `olympiad_seeds.py`.

## Когда пересмотреть
При переходе на постоянные идентификаторы сущностей (справочники с историей слияний).
