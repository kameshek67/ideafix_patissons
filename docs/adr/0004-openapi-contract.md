# 0004. OpenAPI — источник контракта, клиент генерируется

- Статус: принято
- Дата: 2026-11-07

## Контекст
Фронтенд и бэкенд пишут разные люди; ручные типы ответов незаметно расходятся с API.

## Решение
- Контракт генерируется из FastAPI в `docs/openapi.json` (`python -m olymp_api.openapi_cli`).
- Типы фронтенда — `packages/api-client/schema.d.ts` (openapi-typescript), вызовы — openapi-fetch.
- Оба файла коммитятся; CI проверяет, что они актуальны.

## Альтернативы
Ручные интерфейсы TypeScript; GraphQL — избыточно.

## Последствия
После любого изменения эндпоинтов или схем — `just openapi` и коммит обоих файлов. Править
эти файлы руками запрещено.

## Когда пересмотреть
Если появятся внешние потребители API — добавить версионирование и changelog контракта.
