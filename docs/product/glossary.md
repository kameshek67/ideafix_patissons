# Глоссарий

| Термин | Значение |
|---|---|
| **БВИ** | Приём без вступительных испытаний: диплом заменяет все экзамены на направление. |
| **100 баллов** | Диплом засчитывается как 100 баллов ЕГЭ по профильному предмету (вступительному испытанию). |
| **Особое право** | Общее название льгот БВИ и 100 баллов; у Иннополиса конкретное право задают правила приёма (`Особое право (БВИ/100)`). |
| **Подтверждение ЕГЭ** | Условие льготы: ЕГЭ по предмету олимпиады не ниже порога (обычно от 75). Колонки `confirm_subject`, `min_ege`. |
| **ИД** | Индивидуальные достижения — дополнительные баллы к сумме ЕГЭ (медаль, ГТО, волонтёрство, олимпиады вне льгот). В базе пока только «УрФУ +4 балла». |
| **Фаст-трек** | Ускоренное зачисление в ЦУ (Центральный университет) — отдельный тип льготы. |
| **РСОШ / перечень** | Перечень олимпиад школьников, утверждаемый Минобрнауки ежегодно; у каждой олимпиады и профиля — уровень I, II или III. |
| **ВсОШ** | Всероссийская олимпиада школьников. Заключительный этап даёт БВИ на профильные направления в любой вуз. |
| **Олимпиада** | Каноническая запись справочника (`olympiads`, 173 шт.): «Высшая проба», «Физтех», НТО… Варианты написания и сокращения — алиасы. |
| **Профиль олимпиады** | Предметное направление внутри олимпиады («математика», «информатика»). Льгота даётся за пару «олимпиада + профиль» (`olympiad_profiles`, 635 шт.). |
| **Уровень** | Уровень пары «олимпиада + профиль» в перечне РСОШ (I — высший). Вузы дают разные льготы по уровням. |
| **Степень диплома** | Победитель (`w`) или призёр (`p`). Многие вузы дают БВИ только победителям. |
| **Направление (программа)** | Образовательная программа вуза с кодом (`01.03.02`) — `programs`, 659 шт. |
| **Строка льготы** | Запись `benefits`: направление × олимпиада × профиль × уровень × тип льготы + условия. |
| **Слой** | Происхождение строки: `detailed` — из таблицы вуза, `derived` — выведена из правила «по профилю», `summary` — общее правило текстом, `raw` — исходное перечисление. |
| **«По профилю»** | Правило вида «любая олимпиада перечня I–III уровня по информатике» — разворачивается в строки слоя `derived`, в интерфейсе — бейдж «по профилю». |
| **Ключ (squash key)** | Нормализованное название из одних букв: стабильный идентификатор олимпиады или профиля между пересборками базы (ADR 0007). |
| **Диплом (строка)** | `ключ_олимпиады.ключ_профиля.степень.класс.год`, например `высшаяпроба.математика.w.11.2025`. |
| **Сборка базы** | `olymp-ingest`: XLSX → PostgreSQL одной транзакцией. |
| **MAX** | Российский мессенджер; мини-приложение — сайт, который открывается внутри MAX. |
| **initData** | Подписанные данные запуска мини-приложения MAX: по ним API узнаёт пользователя. |
| **startapp** | Параметр ссылки `https://max.ru/<бот>?startapp=<payload>`: открывает мини-приложение на нужном экране. |
| **MAX Bridge** | JS-библиотека MAX (`window.WebApp`): кнопка «Назад», ссылки, «Поделиться», тактильный отклик. |
| **Кампания** | Приёмная кампания года (сейчас 2026). Дипломы действуют, если олимпиада была в 2023–2026 годах (если вуз не указал иное). |
