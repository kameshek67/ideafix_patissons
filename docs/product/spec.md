# ТЗ продукта «Олимп»

- Версия: 1.0 (2026-11-07)
- Статус: действующее; меняется PR-ом вместе с фичами
- Связанные документы: [glossary.md](glossary.md), [limitations.md](limitations.md), [specs/](../specs/README.md)

## 1. Проблема

Олимпиадник 9–11 класса не может быстро понять, что ему дают его дипломы. Правила льгот —
десятки PDF приёмных комиссий с разными формулировками: «БВИ только победителям», «за 10–11
класс», «при ЕГЭ от 75», «любая олимпиада перечня I уровня по профилю». Школьник, родитель и
учитель тратят часы на сайтах вузов и всё равно рискуют ошибиться.

## 2. Цель

Дать прямой ответ: **где мой диплом даёт БВИ или 100 баллов, при каких условиях и где это
написано**. Каждый ответ сопровождается ссылкой на документ вуза.

## 3. Пользователи

| Роль | Что нужно | Где пользуется |
|---|---|---|
| Школьник 9–11 класса | Понять ценность своих дипломов, выбрать олимпиады под вуз мечты | Телефон, MAX |
| Родитель | Проверить шансы ребёнка, сравнить вузы | Телефон / компьютер |
| Учитель, классный руководитель | Видеть льготы учеников, советовать олимпиады | MAX (бывший Сферум), компьютер |

## 5. Нефункциональные требования

| ID | Требование |
|---|---|
| NFR-1 | **Достоверность.** Каждая строка льготы — со ссылкой на документ вуза. Выведенные строки (`derived`) помечены. Сервис не обещает льготу без оговорки «проверьте в правилах приёма». |
| NFR-2 | **Мобильность.** Основной экран — телефон 360–430 px в MAX; всё работает и на десктопе. |
| NFR-3 | **Скорость.** Ответ поиска p95 < 300 мс на прогретом кэше, первая отрисовка < 2 с на 4G. |
| NFR-4 | **Работа без MAX.** Сайт полностью работает в обычном браузере; MAX добавляет вход и обмен. |
| NFR-5 | **Персональные данные.** Храним минимум (id MAX, имя из данных запуска, дипломы). Не логируем, не передаём третьим лицам и в LLM. Данные учеников учителю — только с согласия ученика. |
| NFR-6 | **Безопасность.** Подпись данных запуска проверяется на сервере; лимит запросов; заголовки безопасности; секреты только в `.env`; запись — только с origin сайта. |
| NFR-7 | **Доступность.** Контраст текста ≥ 4.5:1, управление с клавиатуры, подписи у полей и кнопок-иконок. |
| NFR-8 | **Воспроизводимость.** Сборка базы детерминирована, весь стек поднимается одной командой (`docker compose up`). |
| NFR-9 | **Качество кода.** CI: линтеры, типы, границы модулей, тесты с настоящей базой, актуальность контракта API, поиск секретов. |

## 7. Вне рамок (до конца хакатона)

- Автоматический разбор PDF вузов LLM-конвейером и обновление данных чаще раза в сезон.
- Админка проверки данных, эталонная разметка.
- Вход вне MAX (почта, VK ID, Госуслуги).
- Платные функции, реклама.

## 8. Демо для жюри (сценарий)

1. Открыть бота в MAX → «Открыть «Олимп»».
2. «Олимпиады» → «вышка» → профиль «математика» → вузы → льготы НИУ ВШЭ.
3. «Дипломы» → добавить «Высшая проба, математика, победитель, 11 класс, 2025» → итоги, вузы
   с БВИ, причины неподходящих строк; ввести баллы ЕГЭ → «не хватает N баллов» (F-03).
4. «Поделиться» итогами в чат → открыть ссылку со второго аккаунта (F-01).
5. ИИ-помощник: «люблю программирование, есть призёрство НТО» → олимпиады, вузы, план (F-02).
