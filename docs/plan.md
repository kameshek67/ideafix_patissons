# План и что сделано

Подробности устройства — [architecture.md](architecture.md), проверки качества — [eval.md](eval.md),
эксплуатация и выкатка — [operations.md](operations.md).

## Сделано (ноябрь 2026)

**Кампания 2027**
- Дипломы 2024–2027 годов; год поступления — настройка (`OLYMP_ADMISSION_YEAR`).
- Этап ВсОШ в форме диплома: региональный этап не даёт БВИ и 100 баллов.
- Перечень РСОШ 2026/27 с rsr-olymp.ru: пометка «нет в перечне 2026/27», уровни профилей по новому перечню.
- Переключатель «Правила 2027»: призёрам перечневых олимпиад 2026/27 и позже — 100 баллов вместо БВИ, учитываются
  дипломы 10–11 класса. Основание — поправки в ст. 71 закона об образовании, приняты Госдумой 25.11.2026
  (по сообщению «Парламентской газеты»; подписание не проверено).

**Честная выдача**
- Строка без «кому» для призёра — «проверить», а не совпадение.
- Вузы без таблицы льгот названы в итоге подбора; «по закону» — для ВсОШ и сборных, где у вуза нет своих строк.
- Льготы ВсОШ и международных олимпиад больше не теряются при сборке.

**Данные из документов вузов**
- Единый формат записи с цитатой и страницей, извлечение из PDF и xlsx кодом.
- Слой `document` в базе: у МАИ, МЭИ, РАНХиГС появились таблицы, МГУ и ИТМО пополнились.
- Разбор новых документов по ссылке оператора: задача → извлечение → разница с текущими данными → принять или отклонить
  (`/v1/ops/*`, страница `/ops`); еженедельная проверка источников.

**Качество**
- Эталон извлечения (10 документов) и отложенный эталон (6 документов, 543 записи): извлечение — точность 90%,
  полнота 74%, без ошибок «кому»; старая таблица на тех же страницах — 0,4% и 1,8%.
- Стабильный ключ строки, снимок выдачи и его проверка в CI.
- Помощник: 69 вопросов с ожиданиями из базы, проверка фактов кодом, справочный поиск по документам; выбрана
  DeepSeek flash (единственная прошла порог на полном наборе).
- Жалоба «не совпадает с документом» у каждой строки, статусы, подтверждённые жалобы становятся регрессиями.
- Страница «Качество данных» (`/quality`).

**Для пользователя и внешних сервисов**
- «Цель → олимпиады» для 8–10 классов: до трёх направлений, рейтинг олимпиад.
- Поиск олимпиады с профилем («нто ии»), карточки олимпиад, быстрый список вузов.
- MCP-сервер поверх API и выгрузка открытого датасета.

## Не сделано и почему

- Выкатка на новый сервер — в последний день, по чек-листу из [operations.md](operations.md).
- Сводка для учителя — не успели; нужна модель согласия ученика.
- Точность всей базы не измерена: эталон — выборка.
- Помощник отправляет вопросы зарубежному провайдеру; для школ нужен российский.
- Документ Сеченовского университета не разбирается (перекошенные колонки), у СПбГУ не сопоставлены
  республиканские олимпиады ДНР и ЛНР.
- Тест с настоящими школьниками не проводился.
